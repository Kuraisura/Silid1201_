                         SETUP INSTRUCTIONS

STEP 1: ADD FLASHLIGHT TO YOUR PLAYER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Select your Player GameObject in the Hierarchy
2. Click "Add Component" in the Inspector
3. Search for "FlashlightController"
4. Add it to your player

STEP 2: CONFIGURE THE FLASHLIGHT (Optional - Auto-Setup Works!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The flashlight will auto-create if not found, but you can customize:

▸ LIGHT PROPERTIES:
  - Intensity: 2.5 (brightness)
  - Range: 20 (how far the light reaches)
  - Spot Angle: 50° (width of the beam)
  - Inner Spot Angle: 25° (smooth center)

▸ VISUAL EFFECTS:
  - Smooth Transition: ON (smooth fade in/out)
  - Enable Flicker: ON (realistic light flicker)
  - Flicker Amount: 0.05 (subtle variation)

▸ BATTERY SIMULATION (Optional):
  - Simulate Battery: OFF by default
  - Battery Life: 300 seconds (5 minutes)
  - Enable this for added challenge!

STEP 3: POSITION THE LIGHT (Optional)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If you want to manually position:

1. Find/Create child GameObject under Camera called "Flashlight"
2. Position it: X: 0.2, Y: -0.1, Z: 0.3 (or adjust to your preference)
3. Drag this GameObject to the "Flashlight" field in FlashlightController

STEP 4: REGENERATE INPUT SYSTEM (IMPORTANT!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Unity needs to regenerate the input class:

1. In Project window, go to: Assets/InputSystem_Actions.inputactions
2. Click on it to select it
3. In the Inspector, click "Generate C# Class" button
4. Wait for Unity to recompile

STEP 5: TEST YOUR FLASHLIGHT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Press PLAY
2. Press F KEY to toggle flashlight on/off
3. Try pressing SPACEBAR - nothing should happen (jump removed!)

                         SCRIPTING API
═══════════════════════════════════════════════════════════════════════════════

Access from other scripts:

// Get the flashlight controller
FlashlightController flashlight = player.GetComponent<FlashlightController>();

// Methods:
flashlight.ToggleFlashlight();      // Toggle on/off
flashlight.TurnOn();                // Force on
flashlight.TurnOff();               // Force off
flashlight.IsOn();                  // Check if on (returns bool)
flashlight.GetBatteryPercent();     // Get battery % (0-100)
flashlight.RechargeBattery();       // Refill battery

═══════════════════════════════════════════════════════════════════════════════
                         TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ F KEY DOESN'T WORK:
   → Make sure you regenerated the Input System C# class
   → Check that PlayerInput component has the correct Action Asset
   → Verify "Flashlight" action exists in Input Actions

❌ NO LIGHT APPEARS:
   → Check if "Flashlight" field is assigned in Inspector
   → Make sure the Light component exists
   → Check if light is enabled and intensity > 0

❌ SPACEBAR STILL JUMPS:
   → Make sure you saved all files
   → Reload/restart Unity
   → Check BetterPlayerMovement.cs doesn't have OnJump method

❌ INPUT NOT RESPONDING:
   → Select your Player GameObject
   → Check if it has "Player Input" component
   → Verify "Actions" field points to InputSystem_Actions
